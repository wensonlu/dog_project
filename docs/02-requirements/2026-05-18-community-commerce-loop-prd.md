# 社区驱动商城闭环 PRD（AI 提炼清单 + 订单 + 打卡回流）

## Phase 0 - 对齐与约束
一句话目标：把论坛内容消费升级为“AI可解释推荐 + 快速下单 + 打卡回流社区”的闭环，提升用户粘性和转化。

范围边界：
- v1 In-Scope：帖子页 AI 提炼用品清单、订单页打卡开关、7天打卡任务、回流入口。
- v1 Out-of-Scope：真实支付成功回调联动、复杂营销活动、达人分佣体系。

## 1. 背景与问题
当前商城与社区割裂，用户缺乏“为什么买”和“买完做什么”的连续体验，导致转化弱、复访低。

## 2. 目标与指标
1. 让社区内容成为商城转化入口。
2. 让下单后行为回流社区形成持续互动。

核心指标（上线后14天）：
1. `forum.ai_kit.show -> click_checkout` 点击率 >= 12%。
2. 社区导单占比（订单来源为论坛）>= 20%。
3. 打卡任务创建率 >= 35%。
4. D1 打卡留存 >= 25%。

## 3. 用户故事
1. 作为新手用户，我希望看帖子时直接看到“适合我的用品建议”，不用自己筛。
2. 作为下单用户，我希望买完能有一个简单计划（7天打卡）指导我使用。
3. 作为运营，我希望看到“内容->下单->回流”的完整漏斗。

## 4. 范围定义
### 4.1 v1 In-Scope
1. 论坛详情页新增 `AI提炼用品清单`（3-5件商品+推荐理由+证据片段）。
2. 清单支持 `一键去下单`，跳转现有订单页并携带商品参数。
3. 订单页新增 `加入7天打卡任务` 开关（默认开启）。
4. 新增打卡页（任务进度、每日打卡、回到帖子）。
5. 个人中心/论坛页新增 `我的打卡` 入口。

### 4.2 v1 Out-of-Scope
1. 自动代扣或支付网关联动。
2. 多任务并行打卡编排。
3. 高级成长体系（积分商城、等级勋章）。

## 5. 关键流程
### 5.1 成功流
1. 用户进入论坛帖子。
2. 系统展示 AI 提炼用品清单。
3. 用户点击“去下单”进入订单页。
4. 用户确认地址并开启打卡开关。
5. 任务创建成功，进入7天打卡页。
6. 用户每日打卡，形成回流互动。

### 5.2 失败流
1. AI 清单生成失败：展示“加载失败 + 重试”。
2. 任务创建失败：订单页提示“创建任务失败，可稍后在我的打卡创建”。
3. 打卡提交失败：提示重试并保留草稿。

### 5.3 取消流
1. 用户关闭打卡开关：仅下单流程继续，不创建任务。
2. 用户中途退出打卡页：任务状态保留，可随时继续。

## 6. 验收标准（DoD）
1. 帖子页可稳定展示 AI 清单，含理由与证据。
2. 清单点击可跳转订单页并带商品参数。
3. 订单页可创建7天打卡任务。
4. 打卡页支持至少1次打卡提交并可查询状态。
5. 埋点覆盖曝光、点击、创建任务、打卡四大事件。
