# 内容合并与宠物用品商城 PRD

## Phase 0 - 对齐与约束
一句话目标：将“百科+故事”收敛为统一内容入口，并新增“宠物用品商城”形成领养后消费闭环，提升内容浏览效率与商业转化。

范围边界：
- v1 In-Scope：底部导航合并为内容 Tab、新增商城 Tab、商城列表与商品详情入口、基础下单引导（非真实支付）。
- v1 Out-of-Scope：真实支付清结算、库存实时锁定、商家后台、优惠券系统。

## 1. 背景与问题
当前底部导航“百科”“故事”并列，用户在知识与案例内容间跳转成本高；平台缺少宠物用品商业触点，无法承接领养后高频消费场景（粮食、牵引、清洁、医疗保健）。

## 2. 目标与指标
业务目标：
1. 降低内容入口选择成本，提升内容访问深度。
2. 建立商城 MVP，验证用品转化漏斗。

核心指标（上线后 14 天观察）：
1. 内容 Tab 点击率较百科/故事单独入口总和提升 >= 15%。
2. 商城 Tab 日活渗透率 >= 18%。
3. 商品详情到“去下单”点击转化率 >= 8%。

## 3. 用户故事
1. 作为新手领养人，我希望一个入口就能看养宠知识和真实案例，减少来回找入口。
2. 作为已领养用户，我希望快速买到与宠物阶段匹配的用品。
3. 作为平台运营，我希望看到商城点击与转化数据用于判断是否扩量。

## 4. 范围定义
### 4.1 v1 In-Scope
1. 底部导航：
- “百科”“故事”合并为“内容”。
- 新增“商城”Tab。
2. 内容页：
- 双分区（百科精选 + 幸福故事）。
- 提供“查看更多”跳转至原有 Wiki/Stories 路由。
3. 商城页：
- 分类筛选（主粮/零食/清洁/出行/健康）。
- 商品卡片（图、标题、价格、评分、标签）。
- 商品详情页（静态/假数据），含“加入购物清单”“去下单”。
4. 埋点：
- 内容入口点击、商城入口点击、商品详情点击、下单按钮点击。

### 4.2 v1 Out-of-Scope
1. 真实支付、订单履约、退款。
2. 个性化推荐排序。
3. 会员价、拼团、秒杀等营销机制。

## 5. 关键流程
### 5.1 成功流
1. 用户点击底部“内容”Tab。
2. 浏览百科与故事混合入口，进入细分列表。
3. 用户点击“商城”Tab。
4. 浏览商品列表，进入详情，点击“去下单”（跳转占位页或外链）。

### 5.2 失败流
1. 商品数据拉取失败。
2. 页面展示错误态与“重试”。
3. 重试成功后恢复列表。

### 5.3 取消流
1. 用户在商品详情点击“返回商城”。
2. 保留筛选状态与滚动位置，避免重复查找。

## 6. 验收标准（DoD）
1. 底部导航不存在独立“百科”“故事”项，替换为“内容”。
2. 底部导航出现“商城”，点击可达商城首页。
3. 内容页可访问百科与故事两个分区并可跳转原有页面。
4. 商城页支持分类切换、商品详情进入、下单按钮触发。
5. 关键埋点事件可在日志中观测。
