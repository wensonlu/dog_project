# 宠物会说话卡片（搞笑玩梗）PRD

## 1. 背景与问题
当前宠物浏览页以静态图文为主，用户停留与分享动力不足。需要一个低学习成本、高记忆点的 AI 互动模块，提升卡片浏览深度与收藏/分享转化。

## 2. 目标与指标
- 目标：在不牺牲真实信息与平台调性的前提下，增加“好玩感”和传播性。
- 核心指标（上线后 2 周观测）：
  - 语音播放点击率 >= 25%
  - 语音完播率 >= 45%
  - 宠物卡片收藏率提升 >= 12%
  - 卡片分享率提升 >= 20%

## 3. 用户故事
- 作为浏览用户，我希望宠物能“开口玩梗”，让我快速建立情感连接。
- 作为潜在领养人，我希望内容好笑但信息真实，避免误导。
- 作为运营，我希望可控管理文案风格与风险边界。

## 4. 范围定义
### v1 In-Scope
- 卡片展示“玩梗气泡文案”
- 点击“让它开口”播放 TTS（6-10 秒）
- 支持“换一句”轮播候选文案
- 全局静音开关、字幕同步
- 基础风险词过滤 + 事实字段校验

### v1 Out-of-Scope
- 口型动画驱动
- 用户自定义人设
- 多语种配音
- 实时语音克隆

## 5. 关键流程
### 5.1 成功流
1. 用户滑到宠物卡片
2. 前端请求/命中缓存文案
3. 展示首句梗文案气泡
4. 用户点击“让它开口”
5. 播放缓存或新合成 TTS
6. 用户收藏/分享或切换下一张卡片

### 5.2 失败流
1. 文案生成失败 -> 降级为模板文案
2. TTS 合成失败 -> 仅展示字幕 + 重试按钮
3. 风险审查不通过 -> 替换安全候选句

### 5.3 取消流
1. 用户关闭语音总开关
2. 当前播放立即停止
3. 后续仅保留文字气泡，不自动触发音频

## 6. 验收标准（DoD）
- 每张卡片可稳定展示 >=1 条梗文案
- 点击播放成功率 >= 98%（含缓存与重试）
- 风险文案命中后 100% 不出现在前台
- 关键埋点齐全：impression/click_play/play_3s/play_end/switch_line/share/favorite
- 支持移动端主流视窗（375x812 起）

## 7. 一句话目标 + 范围边界（Phase 0 输出）
- 一句话目标：让宠物在滑卡场景中以“互联网玩梗”方式开口说话，提升趣味互动与转化。
- 范围边界：v1 仅做“文字+TTS”的可控生成与播放链路，不含口型动画与高级个性化。
