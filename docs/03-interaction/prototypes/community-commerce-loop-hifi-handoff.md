# Community Commerce Loop Handoff

## 原型文件
1. `community-commerce-loop-hifi.html`
2. `community-commerce-loop-hifi-sim.html`（三屏切换模拟：帖子页 -> 订单页 -> 打卡页）

## data-ui 映射
1. `data-ui="ai-kit-card"` AI清单卡
2. `data-ui="btn-checkout"` 去下单
3. `data-ui="switch-challenge"` 打卡开关
4. `data-ui="btn-create-task"` 创建任务
5. `data-ui="btn-checkin"` 今日打卡

## 交互说明
1. 使用底部“上一步/下一步”可模拟完整闭环路径。
2. 帖子页点击“去下单”会跳到订单页。
3. 订单页点击“创建任务并继续”会跳到打卡页。
4. 打卡页点击“今日打卡”会展示完成卡片与回流按钮。
